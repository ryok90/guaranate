```bash
guaranate 2h              # stay awake for two hours
guaranate                 # stay awake until interrupted
guaranate 45m --display   # keep the display awake too
```

Guaranate is a small macOS command-line utility for managing sleep-prevention
sessions. The name is a play on **guaraná**, the Brazilian stimulant, and
Apple's `caffeinate` command.

:::note[Where the project stands]
Version 0.1 ships timed and indefinite sessions. Commands that are planned but
not yet released — `while`, `until`, `status`, `why`, `--json`, leases — are
listed on the [roadmap](/reference/roadmap/) and are deliberately absent from
these guides until they ship.
:::
